# Contributing to ctk_toggle

Contributions are welcome. The steps below keep changes reviewable and consistent with the rest of the codebase.

## Workflow

1. Fork the repository and clone your fork.
2. Create a branch for your feature or fix.
3. Make focused changes with clear commit messages.
4. Open a pull request describing what changed and why.

## Standards

- Follow the conventions in [STYLE.md](STYLE.md) and [OPTIMIZATION.md](OPTIMIZATION.md).
- Match PEP 8 and the existing formatting; keep the public API stable unless the change is intentional and documented.
- Include a runnable example or test for new behavior where practical.
